# A2A 1.0 升级验收（2026-10-16）

## 版本与范围

- 直接生产依赖从 `@a2a-js/sdk-v0_3`（SDK 0.3.14）改为固定 `@a2a-js/sdk` 1.3.0；截至本次核验，npm `latest` 与[官方发布页](https://github.com/a2aproject/a2a-js/releases/tag/v1.3.0)一致。
- [协议规范修订为 1.0.1](https://a2a-protocol.org/v1.0.1/specification/)，协商版本为 `1.0`。同一 `/a2a` 同时提供 1.0 与 0.3 JSON-RPC；兼容转换使用新版 SDK 内置 `compat/v0_3/server`。旧 SDK 保留为直接开发依赖，用真实旧客户端验证兼容。
- 迁移 Agent Card、方法名、枚举、消息、图像 Part、事件、错误和调用上下文。发现请求缺省版本为 0.3，显式 `A2A-Version: 1.0` 获取新版 Card；错误版本或不匹配的方法/版本组合拒绝执行。
- 保持单 key 信任域、原有三个操作、结构化 data 输入、内存任务及取消。旧版 `blocking` 省略时继续阻塞；新版用 `returnImmediately`。重复取消已取消任务幂等返回。
- 二进制缓存按协议 JSON/base64 字节计量并复制，避免 Buffer 内部表示改变预算；容量不足的更新不会删除原任务。阻塞与非阻塞请求共享四个名额，待启动任务交接给执行器时不重复计数。
- 不新增流式、推送、续写、任务列表、多租户或持久化。
