- 五类 ChartSpec 的 SVG/PNG、中文、中英文混排、主题、真实2x像素、透明背景、换行/长标题/长图例/罕见字符样例；原数据不变。
- option/style/theme 优先级、数组替换、静态限制，非法/空/缺失/重复分类、负数与饼图边界、像素超限、脚本/外链/原型污染、SVG输出主动内容校验。
- HTTP真实内容类型、request ID、鉴权、400/401/413/422/503，OpenAPI合同。
- 官方 MCP SDK 1.30.0 客户端：握手、工具枚举、PNG image、SVG text、metadata、工具失败和错误凭据；真实关闭客户端连接后Worker终止。
- 官方 A2A SDK 0.3.14 客户端：Agent Card发现、wire 0.3.0、SVG/PNG文件artifact、task读取、失败、非阻塞取消、错误凭据、未知任务、过期和重启语义。
- 渲染fixture实际占满CPU后被SIGKILL；测试确认旧PID不存在，并验证后续进程恢复、队列满、取消、崩溃；子进程未继承LLM_API_KEY。
- Mastra真实适配器对本地503上游只发出一次HTTP请求；业务层错误不带上游原文。字段错误最多两次；原始数据本地绑定；AI总时限、取消和并发2。

测试文件：`tests/core.test.mjs`、`tests/a2a.test.mjs`、`tests/llm.test.mjs`。这些是多个子断言组成的15组测试，不是15个孤立样例。

## 最终镜像与运行矩阵

使用 OrbStack。本机原生 arm64；amd64 使用仿真运行，不代表已在原生x86生产服务器验收。

- arm64：`echarts-agent:local-arm64`，image ID `sha256:9e3332a6a2b5cbb9afb591e61f3605d5a312558b57fe1f271a03ba9ba32e9af1`
- amd64：`echarts-agent:local-amd64`，image ID `sha256:16c369dfaa59aaffbfd570eda7f4ab42e22f2d451dcff4cd5a17c0de0fccb506`

规格统一为2CPU、768MiB内存、pids-limit128、非root UID1000、只读根、64MiB临时目录。每轮20次960×540 PNG请求，并发4。所有轮次均包含HTTP option/SVG、ChartSpec/PNG（1920×1080）、真实MCP client、Bearer认证和模型开关检查。

| 架构 | 网络 / A2A / 模型 | p50 / p95 | 测后观察内存 | 正常停止 |
| --- | --- | --- | --- | --- |
| arm64 | none / 关闭 / 关闭 | 19 / 32ms | 430.9MiB | 197ms，exit0 |
| amd64仿真 | none / 开启 / 关闭 | 56 / 102ms | 572.9MiB | 170ms，exit0 |
| arm64 | bridge / 开启 / 百炼 | 34 / 68ms | 336.9MiB | 210ms，exit0 |

## 视觉复核

人工查看 `artifacts/acceptance/{bar,line,pie,scatter,radar}.png`：中文可读，图形和图例对应、正负数与0正确，主题背景正常。检查后修正暗色主题轴文字/网格对比度。另查看长标题/换行/长图例/罕见字符及透明背景样例，透明像素由测试读回alpha=0。

SVG保留字体引用，不能保证接收方有Noto字体。PNG将字形固化；样例可读不等于覆盖全部Unicode。多指标、超长多行文本、极小尺寸仍需调用方调整尺寸/标签，未承诺自动排版任意报表。

## 未覆盖与运行边界

- 未进行生产部署、公开网络压测、长时间稳定性或多租户安全认证；静态key代表共同信任域，OAuth不在当前实现。
- A2A任务在有界内存中短期保留，最多10分钟或容量淘汰，重启丢失；无续写、streaming、push notification。
- 子进程heap限制不覆盖Sharp全部native内存；容器OOM仍可能终止主进程。持续Worker故障会使readiness失败，需要调查并重启。
- 只保证文档定义的ECharts静态安全子集；没有浏览器交互、地图/GL/custom、外部图片和数据连接器。
- Provider只实测百炼。模型设计可能语义不合预期，调用方应检查返回的最终spec/option；服务保证原始数值绑定，不保证意图理解总是正确。
