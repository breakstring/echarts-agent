## 变更与自动化

- 新增 gauge、funnel、heatmap、tree、treemap、sunburst、sankey，总计12类。option、ChartSpec、ChartPlan 以及 HTTP/MCP/A2A 使用共享合同。
- `npm run typecheck` 通过；最终 `npm test` 29组全部通过、0失败、0跳过。
- 七类分别验证 SVG、2x PNG（1920×1080）、原始 option 回放、原输入不变；浅/暗主题 PNG 均实际生成，检查了全部七类浅色样例及热力图/树图暗色样例。
- A2A 真实 SDK 客户端逐类返回 PNG；MCP 验证热力图/矩形树图/桑基图，HTTP capabilities 与 OpenAPI 的12类型保持一致。
- 校验无效层级、断链/有环/重复ID/深度与节点数、负数与父子总量冲突、十进制求和误差；桑基图有向环/自环/重复边/缺失节点/非正流量；热力图重复坐标、仪表盘范围、安全 visualMap、排除类型。
- 修正仪表盘刻度间距、热力图文字对比度、矩形树图上层标题和虚拟根标签、旭日图/漏斗文字描边。

## 使用与边界

请求示例见 [examples/extended](../../examples/extended)，输入语义与限额见 [设计合同](../specs/2026-09-16-echarts-agent-design.md)。层级图最多1000节点/8层，桑基图最多500节点/2000边；数据必须显式提供，不隐式聚合或修补。极密图形/长标签仍可能隐藏或截断，不承诺任意画布下自动布局。

地图、GL、自定义脚本和动态交互不在范围内；没有新增依赖、初始化Git、提交、推送、镜像发布或生产部署。
